# Toxic Trace Atlas

**Created by Perplexity for OsintNeoAi**

An original, self-contained 3D “evidence constellation” prototype inspired by the spatial-OSINT and litigation-forensics direction of `Tonypost949/OsintNeoAi`.

## What it does
- Renders sites as interactive 3D nodes on a dark evidence canvas.
- Color-codes an illustrative risk index from low to critical.
- Opens a per-site evidence chain: dates, events, contaminants, and status.
- Uses only embedded demo data; no external calls, credentials, or personal data.

## Run it
Open `index.html` in any modern browser. Drag to orbit, scroll to zoom, and click a node.

## Original twist
Instead of another dashboard or document matrix, it treats an environmental case as a **constellation**: each site is a star, each connection a potential investigative thread, and each click unfolds a chronological evidence narrative.

## Important limit
The included sites, events, and contaminants are fictional demonstration records. Before real-world use, replace them with authorized, source-linked public records and retain provenance for every claim.
