Ingestion & Settlement

⚙️ The E2E Data Ingestion Pipeline

How raw forensic files are ingested, AI-enriched, cryptographically verified, and paid out.

1

The Workspace UI (Frontend)

Frictionless chat environment (workspace_chat.html) with multimodal capture:

  • Multimodal Capture: Upload documents, capture pictures via WebRTC HTML5 canvas, or record voice memos with MediaRecorder.
  • Sybil Defense (Staking Gate): Client computes SHA-256 locally and prompts MetaMask to execute stakeAndSubmit(hash) on StakingGate (100 OSINT stake required to eliminate bots).
2

Evasive Azure Proxy (API Router)

FastAPI backend (workspace_api.py) processes raw multipart FormData:

  • File Decoding: Text and PDF documents decoded; media tagged for vision processing.
  • BigQuery V1 (Raw Append): Payload immediately written to BigQuery as version_id = 1 using Workload Identity Federation (WIF) credentials (zero static keys).
3

Background AI Consumer

Heavy extraction pushed to asynchronous queue (background_consumer.py):

  • Gemini Extraction: Gemini-1.5-Pro micro-worker extracts entities (FOIA headers, legal citations, persons) and assigns domain tags (e.g. [OSINT], [Tax-Funded]).
  • BigQuery V2 (Enriched Append): Structured metadata is appended as version_id = 2. Original raw file remains completely immutable.
4

The Web3 Oracle Bridge

Upon AI validation, Python backend signs on-chain Oracle transactions via web3.py:

  • Lifting Quarantine: Oracle calls reviewSubmission(hash, true) on StakingGate, refunding the 100 OSINT stake + granting +10 Reputation points.
  • Registering Lineage: Oracle maps ancestry via registerDataBlock(assetHash, parentHash, minerAddress, domainTags) on MultiPoolEscrow.
5

Automated Multi-Pool Payouts

When a case is solved and organizations deposit fiat-backed USDC into the escrow:

  • UTXO Provenance Graph: Contract traverses parentHash pointers to map exactly who contributed evidence.
  • The 40/30/30 Split: Deterministically distributes USDC: 40% Catalyst (Discoverer), 30% Corroborator (Enricher), 30% Closer (Lead Auditor).
  • Domain Minting: Dynamically mints secondary utility rewards (OSINT / TFT) to contributors' Web3 wallets based on domain tags.
Zero-Trust Security Model

🔒 The 5 Vulnerabilities Sealed

Engineered from day one to withstand state-level tampering, Sybil spam, and API throttling.

1. Pointer Corruption

Eliminated by strict cryptographic parentHash linking (UTXO style), preventing history rewrites or hijacked credit.

2. File Forgery

Prevented by SHA-256 client-side hashing at the instant of capture and append-only BigQuery database schemas.

3. Sybil Attacks

Mitigated by the Web3 Staking Gate requiring 100 OSINT token collateral on every submission, destroying spam incentives.

4. Compute Bottlenecks

Solved by offloading heavy extraction to the asynchronous background_consumer.py queue.

5. Rate-Limit Guillotine

Bypassed using off-peak cron caching (bulk_caching_queue.py) instead of live API queries.
