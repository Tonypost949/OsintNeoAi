## 4. Provenance & method

- Every occurrence stores: source file (relative path), SHA-256 of the exact file version, line number, and a context snippet.
- Deduplication is per (file, IP); the rollup aggregates across files.
- Classification via Python `ipaddress` (public = globally routable).
- PDFs are extracted with `pdftotext -layout` when available; scanned/image-only PDFs yield no text and are skipped.
- Extraction is deterministic: same tree + same tool version => same outputs. Re-run to refresh after new files land.
