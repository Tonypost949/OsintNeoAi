Authorizing additional features

Note:

To perform this operation, you need to refer to the authorization information sent via e-mail by Esri Customer Service.

  1. Launch ArcGIS License Server Administrator from Start > Programs > ArcGIS > License Manager > License Server Administrator.
  2. Click Authorization in the table of contents.
  3. Click Authorize Now to launch Software Authorization Wizard.
  4. Follow the instructions to complete the authorization process and return to ArcGIS License Server Administrator.
