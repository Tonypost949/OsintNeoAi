ArcGIS Administrator

ArcGIS Administrator is the utility installed with the ArcGIS for Desktop, ArcGIS Engine, and Esri CityEngine software, which allows you to manage your license environment. You can define the product type, set a license manager, authorize single-use licenses, see license availability, borrow and return concurrent-use licenses, and repair licenses.
