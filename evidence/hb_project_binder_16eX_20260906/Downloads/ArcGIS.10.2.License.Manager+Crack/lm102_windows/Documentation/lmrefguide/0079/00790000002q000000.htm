Existing users

For users who currently have a previous version of ArcGIS License Manager and wish to migrate to the latest 10.2 version of ArcGIS License Manager, follow the instructions below:

10.0 and 10.1 License Managers

If you are currently using ArcGIS 10.0 and ArcGIS 10.1 License Managers, view details under the topic License Manager Installation and Startup.

9.x License Manager

If you are currently using a 9.x License Manager, you first need to uninstall this older version to proceed with the installation of the ArcGIS License Manager 10.x. License files at version 9 or earlier will not work with this new version of the License Manager. You will need to first authorize licenses on the license server using the new authorization information sent via email by Esri Customer Service before starting the license service.

Contacting Esri Customer Service

If for any reason you are unable to locate your authorization information, you can contact Esri Customer Service and request that it be resent.

In the United States, you can contact Esri Customer Service by calling 888-377-4575 or visit the Esri Customer Service site.
