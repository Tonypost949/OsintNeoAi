## JOB 4 — DAILY SOLAR CARD (every day, no end date)
Each day, build ONE Solar Card from measured public data and post it
ONCE to the OSINTNeoAi Page (page_id 1264271163441359).

### Pull (all free, keyless — pull the numbers, never invent them)
- NOAA SWPC (services.swpc.noaa.gov): Kp max of the day, biggest GOES
  X-ray flare of the day + its active region, solar wind speed, Bz min,
  F10.7 flux.
- NASA/CCMC DONKI: any CME of the day — Earth-directed yes/no, expected
  arrival if published.
- Schumann note where available (Tomsk / Cumiana 1st-mode, amplitude,
  bursts) — if no reading is reachable that day, write "Schumann: no
  reading today" on the card. Never fill it in from memory.
- USGS: largest earthquake of the day (magnitude + place) — this is
  the day's ground-truth anchor on the card.

### Render
- ONE Solar Card image in the S0 Card-of-the-Day STYLE — fields and
  layout idea only: our own OsintNeoAi branding and artwork, never
  copying Suspicious0bservers artwork, logos, or card graphics.
- Card fields: date, Kp max, biggest flare + region, solar wind, Bz,
  F10.7, CME line, Schumann line, biggest quake line, and a
  QUIET / ACTIVE label decided by the numbers (Kp >=5 or an M+ flare
  or an Earth-directed CME = ACTIVE, otherwise QUIET).
- On the card and in the post, link that day's S0 News YouTube video
  (Suspicious0bservers, Ben Davidson) — link out only, do not re-host
  or re-upload his video.

### Post
- ONE Page post, starting exactly: "SOLAR OVERLAY — "
- Body: the day's numbers in plain form, whether the day was quiet or
  active, and the world-OSINT event it overlays (the same day's OSINT
  EYE VIEW event from Job 3 where it fits).
- End with: "Every record. Every day."
- Attach the Solar Card image to the post.

### Rules
- Duplicate check first, every day: read the Page's posts for today
  before posting. If a "SOLAR OVERLAY — " post for today already
  exists, do not post a second one.
- Report EVERY day in the MUSE CHANNEL Doc: date, the numbers used,
  card made yes/no, post state + post URL, any failure exactly as it
  happened. Silence is failure — if you cannot run, post why.
- NO correlation claim: the card and post state that day's measured
  numbers only. Whether solar activity correlates with world events
  is what the website backtest panel tests over many days — never
  claim a link from one day, one flare, or one quake.
- Track this job on the unified Google Tasks list
  "OsintNeoAi — Unified Tasks", same as Jobs 1-3.
