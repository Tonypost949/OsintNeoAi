WebDiver - Website Analysis Tool

WebDiver is a Python-based tool designed for extracting and analyzing comprehensive information from websites.

Features: Caters specifically to the OSINT community, providing robust capabilities for web data extraction, link analysis, and metadata retrieval.

Gathers: Internal/external links, email addresses, metadata, IP information, and comprehensive website structure analysis.
