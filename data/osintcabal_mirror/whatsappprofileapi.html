WhatsApp Profile Data API - CheckLeaked

This page will launch the CheckLeaked WhatsApp API website right to your search query. Be wary of limiting!

Features: WhatsApp profile lookup, account verification, and metadata extraction.

Note: CheckLeaked has rate limits. Use responsibly and avoid excessive queries.

CheckLeaked

Rate Limiting Warning

CheckLeaked implements rate limiting to prevent abuse. Excessive queries may result in temporary blocks. Use this tool responsibly and allow cooldown periods between searches.

How to Use

1. Select the country code from the dropdown

2. Enter the phone number (digits only, no spaces or dashes)

3. Click "Search" to query the CheckLeaked API in a new tab

Example: +1 and 1231231234 queries:
https://whatsapp.checkleaked.cc/pl/11231231234
