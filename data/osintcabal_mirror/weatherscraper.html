Cabal Weather Scraper

// meteorological osint via free weather APIs

Queries multiple free weather APIs to pull current conditions, extended forecasts, active storm alerts, coordinate-based reports, weather station locations, and ZIP/postal-code lookups. All results are exportable to TXT or JSON.

Enter a city name (optionally with state/country). Pulls real-time temperature, humidity, wind, pressure, visibility, and UV index.

7-day extended forecast for any city. Returns daily high/low, precipitation probability, wind, and condition summaries.

Fetches active National Weather Service alerts for a US state code or geographic area. Includes severity, event type, and affected zones.

Query weather by exact latitude/longitude. Returns current conditions plus reverse-geocoded location metadata.

Locates nearby weather observation stations for a city or coordinates. Returns station IDs, names, and distance from query point.

Pull current conditions by US ZIP code or international postal code. Resolves to city, region, and country automatically.
