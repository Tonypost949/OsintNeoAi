OSINTChan

A 4chan OSINT collection tool built on the official 4chan read API (a.4cdn.org) — no API key required. Search board catalogs, pull full threads, enumerate boards, and list archives for investigations.

READ-ONLY PUBLIC DATA

Queries the public 4chan API only (8kun support is planned upstream). Imageboard content can be graphic or hostile — investigate responsibly. #OSINT4Good
