Understand where things are and how they connect

ArcGIS for Microsoft integrates geospatial data and location services into Microsoft platforms. It delivers mapping, visualization, spatial analysis, automation, and geospatial application development capabilities to Microsoft users.

Benefits of ArcGIS for Microsoft

  • Enrich your data with geospatial insights

    Enhance Microsoft 365, Microsoft Fabric, and Power Automate workflows with different types of geospatial data, including lifestyle, spending, and demographic data.

  • Integrate location intelligence into Microsoft platforms

    Empower your team to visualize and analyze geospatial data of any scale to gain a deeper understanding of where things are, their relationships, and the underlying patterns.

  • Incorporate no-code/low-code spatial automation

    Seamlessly integrate ArcGIS capabilities into Power Automate workflows, streamlining process automation while minimizing the need for IT resources and advanced coding skills.

  • Enhance app functionality with location services

    Developers can build robust geospatial and location intelligence applications for both desktop and mobile platforms using ArcGIS Maps SDK for .NET, driving innovation with comprehensive location-based mapping solutions.

  • Support cross-platform spatial data collaboration

    Enable collaboration on geospatial data and applications from a familiar Microsoft environment, reducing cross-platform switches and boosting productivity.

  • Securely share geospatial data within the Microsoft environment

    Facilitate secure and seamless sharing of data through robust identity and access management, as well as role enforcement, to manage who can access your organization’s data and assets.

ArcGIS for Microsoft 365

ArcGIS for Microsoft 365 integrates location analytics and provides access to spatially enabled apps and data in familiar Microsoft 365 applications. It enables everyone in your organization to visualize and analyze content geographically and gain insights from location intelligence.

Explore ArcGIS for Microsoft 365

ArcGIS for Microsoft Fabric

ArcGIS for Microsoft Fabric integrates mapping capabilities and geospatial analytics tools directly into the Microsoft Fabric environment. It enables spatial analysis at any scale using Apache Spark to uncover patterns and trends that can be incorporated into Microsoft Power BI for business reporting and further analysis.

Explore ArcGIS for Microsoft Fabric

ArcGIS for Power Platform

ArcGIS for Power Platform offers no-code/low-code development tools to support the development of geospatial apps and automated workflows. It enables the secure integration of geospatial capabilities and data into workflows across Microsoft and other business systems, driving operational efficiency and improving overall business performance.

Explore ArcGIS for Power Platform

ArcGIS Maps SDK for .NET

ArcGIS Maps SDK for .NET allows you to build 2D and 3D location-based mapping applications that work online and offline. Use .NET MAUI, WinUI, and WPF to build apps for Windows, iOS, and Android that include capabilities like geocoding, geofencing, routing, and navigation.

Explore ArcGIS Maps SDK for .NET

ArcGIS Enterprise on Microsoft Azure

Leverage the full power of a self-hosted infrastructure within a scalable, secure, and reliable cloud environment. Deploying ArcGIS Enterprise on Microsoft Azure enables organizations to improve efficiency and scale resources to meet evolving needs.

Explore ArcGIS Enterprise

ArcGIS Pro on Microsoft Azure Virtual Desktop

ArcGIS Pro deployed on Microsoft Azure Virtual Desktop (AVD) delivers a powerful, flexible geographic information system (GIS) solution by leveraging Azure’s scalable resources to ensure optimal performance. With support for Windows 11 multisession virtual machines, it provides a seamless user experience and maximizes your investment in cloud technology.

Explore ArcGIS Pro
